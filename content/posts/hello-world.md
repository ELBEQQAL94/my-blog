Welcome to the blog. This post exists mostly to prove the pipeline works: it's a
plain markdown file with a bit of frontmatter at the top, rendered into a static
page at build time.

## What this is

A handful of `.md` files in `content/posts`, read off disk and turned into pages.
No database, no CMS, just files in git.

## What's next

More posts, written the same way: drop a file in `content/posts`, give it a
title, date, description, and some tags.
